계정 3개만 준비해 주세요

대부분 브라우저에서 사용할 수 있습니다. 학교의 계정 사용 지침과 각 서비스의 이용 조건을 먼저 확인하세요.

✅ 만들 계정 3개
  • ① 깃허브(GitHub) — 코드를 올려 두는 곳입니다
  • ② 스트림릿 커뮤니티 클라우드 — 그 코드를 실제로 돌리는 곳입니다 (깃허브 계정으로 로그인)
  • ③ AI 서비스 — 코드를 써 줄 도구입니다 (클로드·챗지피티·제미나이 중 하나)
💡 셋의 관계

AI에게 코드 작성을 요청하고, GitHub에 파일을 저장한 뒤, Streamlit에서 웹 앱으로 실행합니다.

① 깃허브 계정

이미 GitHub 계정이 있다면 해당 계정을 사용하세요. 학교에서 계정 사용 방법을 안내했다면 그 안내를 따르세요.

  1. github.com 접속
    github.com → 우측 상단 Sign up
  2. 이메일 · 비밀번호 · Username 입력
    Username은 영어로 적습니다. 앞으로 만들 앱 주소에 그대로 들어가니 짧고 깔끔하게 정해 주세요
  3. 이메일 인증
    메일함에 온 인증 코드를 입력합니다
  4. 완료
    무료(Free)가 기본입니다. 결제 정보를 넣는 화면은 없습니다
✔️ 확인

github.com/사용자이름이 열리면 됩니다. 사용자 이름은 꼭 기억해 두세요.

② 스트림릿 커뮤니티 클라우드

파이썬 코드를 웹앱으로 켜 주는 무료 서비스입니다. 가입이랄 게 따로 없고 깃허브로 로그인만 하면 됩니다.

  1. share.streamlit.io 접속
    share.streamlit.io
  2. Continue with GitHub
    반드시 ①에서 만든 같은 계정으로 로그인합니다
  3. 권한 허용(Authorize)
    저장소의 코드를 앱으로 켜려면 필요한 연결입니다
  4. 완료
    대시보드 화면이 뜨면 성공입니다

③ AI 서비스 (하나만)

학교에서 허용한 AI 서비스를 사용하세요. 이 자료의 프롬프트는 여러 AI 서비스에서 활용할 수 있도록 작성되어 있습니다.

서비스주소메모
클로드claude.ai사용하는 AI 서비스에 따라 화면 구성이 다를 수 있습니다
챗지피티chatgpt.com익숙하시면 이걸로
제미나이gemini.google.com구글 계정이면 바로 됩니다
💡 무료 요금제로도 됩니다

AI가 긴 코드를 한 번에 완성하지 못하면 이어서 요청할 수 있습니다. 결과가 실행되는지 직접 확인하고, 오류가 나면 오류 메시지를 바탕으로 원인을 점검하세요.

🎒 체크리스트

  • 깃허브 가입 완료 — 내 사용자 이름 확인
  • 스트림릿 — 깃허브 계정으로 로그인 성공
  • AI 서비스 하나 로그인 성공
  • 계정 로그인 방법 확인(비밀번호나 인증정보를 공개 문서에 적지 않기)
  • 노트북·충전기 — 실습할 때 사용합니다. 화면이 클수록 편합니다
  • 브라우저는 크롬 권장
🎉 준비 완료

계정 접속과 로그인 상태를 확인했다면 STEP 1 · 인구·고령화 지도로 이동하세요.
