데이터과학 수업자료

실제 데이터를 수집·정리·시각화하고, API와 AI를 활용해 웹 앱을 만드는 실습 자료입니다.

🎯 이 자료에서 다루는 것
  • 인구·고령화 지도 — 공개 데이터를 집계하고 지역별 비율을 지도로 표현합니다.
  • 박스오피스 데이터 — API로 데이터를 요청하고 표와 그래프로 나타냅니다.
  • AI 채팅앱 — AI API를 활용해 대화형 앱을 만들고 대화 기록을 관리합니다.
  • 여러 기능을 하나로 통합하기 — 만든 앱을 여러 페이지로 구성합니다.

🔑 실습 환경 준비
GitHub, Streamlit, AI 서비스와 API 키를 안전하게 다루는 방법을 확인합니다.
STEP 1
인구·고령화 지도
데이터를 집계하고 시군구별 비율을 지도와 표로 시각화합니다.
STEP 2
박스오피스 API
API 요청·응답을 이해하고 인증 키를 코드와 분리해 관리합니다.
STEP 3
AI 채팅앱
AI API를 연결하고 시스템 프롬프트와 대화 기록을 활용합니다.
STEP 4
여러 페이지로 통합
앞서 만든 앱을 하나의 서비스 안에서 이용하도록 구성합니다.

🖼️ 작품 갤러리

🔑 API 키와 개인정보를 안전하게 다루기

API 키를 HTML이나 Python 코드에 직접 적어 공개 저장소에 올리지 마세요. 서비스의 비밀 설정 기능을 사용하고, 실습 데이터나 AI 입력에 본인 또는 다른 사람의 민감한 개인정보를 넣지 않습니다.

💡 활동을 진행하는 방법

각 단계를 따라 실습하고, 실행 결과가 안내와 같은지 확인하세요. AI가 작성한 코드가 작동하지 않으면 오류 메시지를 읽고 원인을 점검합니다. 접혀 있는 완성 코드는 결과를 확인하거나 막힌 부분을 해결할 때 참고할 수 있습니다.
