# vibecoding

정보교사 바이브 코딩 수업 자료를 위한 개인 복사본입니다.

원본 저장소: https://github.com/greatsong/vibe1
원본 웹 교재: https://greatsong.github.io/vibe1/

원본 작성자에게 수업자료로 사용해도 된다는 허락을 받았음을 전제로 복사했습니다. 원본의 출처 및 사용 조건을 유지해 주세요.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `/(root)` 를 선택합니다.

참고: `Code.gs`, `map.html`, `board.html`은 Google Apps Script 백엔드 설정/배포에 의존할 수 있습니다. 해당 기능은 HTML 파일 복사만으로 완전히 독립 실행되지 않을 수 있습니다.
